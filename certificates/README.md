# Certificates Directory

Place your certificate files (images like `.png`, `.jpg` or documents like `.pdf`) in this folder.

To display a local file in the modal, update `script.js` under `certData`:
```javascript
'1stop-ai': {
  ...
  file: 'certificates/internship-certificate.pdf', // or .jpg/.png
  ...
}
```

Google Drive links are also configured to open directly or preview in the certificate modal.
